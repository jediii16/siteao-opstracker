# SITEAO OpsTracker

SITEAO OpsTracker is an inventory and borrowing management system for a student organization.

## Tech Stack

### Frontend

- React
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
- React Router
- Axios
- TanStack Table
- Chart.js

### Backend

- Node.js
- Express
- Prisma ORM
- PostgreSQL
